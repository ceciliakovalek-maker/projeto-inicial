# 🎮Jogo do numero secreto 

## 📌Sobre o projeto 
Este projeto é um jogo simples desevolvido em HTML, CSS e JavaScript.
O objetivo do jogo é adivinhar o número secreto gerado aletoriamente pelo sistema.
